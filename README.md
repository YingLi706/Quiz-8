## Part 1: Imaging Technique Inspiration

### Chosen Example: Ding Yi — Appearance of Crosses, with reference to Anni Albers’ woven textiles

![Reference image 1](ding-yi-print.jpg)

![Reference image 2](anni-albers-weaving.jpg)

I am inspired by Ding Yi’s Appearance of Crosses series, especially his repeated use of “+” and “x” marks across a grid. I also connect this to Anni Alber‘s woven textile patterns, where repeated threads create rhythm and surface texture. What I want to borrow is the stitched, interlaced visual quality: simple marks become layered, textile like images. This technique is useful for my project because code could shift the density, colour and position of the crosses over time, making the image feel woven, dynamic and responsive.

## Part 2: Coding Technique Exploration

### Coding Technique: Grid-based Generative Pattern in p5.js

![Coding technique screenshot](cross-stitch-pattern.jpg)

A grid based generative pattern could help create the woven texture I want to explore. By using repeated horizontal and vertical lines, the image can be built like a digital fabric. Small changes in spacing, colour, thickness and movement could make the grid feel more like interlaced threads than a flat structure. This technique also fits my project because user input could control how dense, loose or colourful the pattern becomes, creating a responsive woven visual system.

p5.js reference: [https://p5js.org/reference/p5/line/](https://editor.p5js.org/losylam/sketches/ObR7xc9iK?)
